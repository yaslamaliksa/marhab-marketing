# مرحبا — نموذج بقالة وتموينات

صفحة عربية متجاوبة بهوية مرحبا البنفسجية والخضراء، تشمل كتالوج منتجات وبحثًا وتصنيفات وقائمة مقاضي، وخريطة المدينة المنورة لحساب التوصيل.

## النشر على GitHub Pages

1. فك ضغط الحزمة على جهازك.
2. أنشئ مستودعًا جديدًا في GitHub باسم `marhaba`، واختر Public إذا كنت تستخدم الخطة المجانية.
3. اختر **Add file → Upload files** وارفع جميع الملفات والمجلدات الموجودة داخل الحزمة، ثم اضغط **Commit changes**. يجب أن يكون `index.html` في جذر المستودع، وليس داخل مجلد إضافي. لا ترفع ملف ZIP نفسه.
4. افتح **Settings → Pages**.
5. ضمن **Build and deployment** اختر **Deploy from a branch**، ثم الفرع **main** والمجلد **/ (root)** واضغط **Save**.
6. انتظر اكتمال النشر. سيظهر الرابط في صفحة Pages، وعادة يكون `https://USERNAME.github.io/marhaba/`، مع استبدال USERNAME باسم حسابك.

إذا لم يظهر الملف المخفي `.nojekyll` عند الرفع، فلا يمنع ذلك عمل هذه الحزمة؛ لا تحتوي مساراتها على مجلدات تبدأ بشرطة سفلية.

## المحتويات والتعديل

- `index.html`: محتوى الصفحة والشعار وبيانات المنتجات والأسعار داخل قائمة `products`.
- `premium.css` و`premium.js`: التصميم المطوّر والحركات، مع احترام إعداد تقليل الحركة.
- `delivery.js` و`delivery.css`: الخريطة والتوصيل.
- `assets/`: شعار مرحبا ورسم سلة المقاضي.
- `vendor/`: مكتبة Leaflet للخريطة.

لا تحتاج الصفحة إلى تثبيت حزم أو خطوة بناء. للمعاينة المحلية شغّل `python3 -m http.server 8000` من مجلد الملفات، ثم افتح `http://localhost:8000`.

## إعدادات التوصيل الحالية

نقطة الانطلاق هي تموينات ومخابز مرحبا في المدينة المنورة عند الإحداثيات `24.4530435, 39.5011547`، وفق رابط الموقع الذي قدّمه صاحب المشروع.

الرسوم 15 ريال لكل 5 كم أو جزء منها، اعتمادًا على المسافة المباشرة التقديرية وليست مسافة الطريق. إذا كان الموقعان متطابقين فالرسوم صفر. مناطق الوسط والشمال والجنوب والشرق والغرب تقسيم تجريبي وليست حدود أحياء رسمية.

المنتجات والأسعار تجريبية. قائمة المقاضي وعنوان التوصيل يُحفظان محليًا على جهاز الزائر؛ لا توجد قاعدة بيانات مشتركة أو إرسال طلبات للبقالة أو دفع إلكتروني. إذن تحديد الموقع يطلبه المتصفح عند استخدام «موقعي الحالي»، ويعمل على HTTPS أو localhost.

تحتاج صور خريطة OpenStreetMap وخط Google Fonts إلى اتصال بالإنترنت. يجب الحفاظ على نسب خريطة OpenStreetMap الظاهر على الخريطة والالتزام بسياسة استخدام بلاطها عند الاستخدام الفعلي: https://operations.osmfoundation.org/policies/tiles/ . تُعرض الخريطة بخيار إدخال الإحداثيات يدويًا عند تعذّر تحميلها.

## الحقوق

الشعار والاسم خاصان بمرحبا. تتضمن الحزمة مكتبة Leaflet تحت ترخيص BSD-2-Clause؛ انظر `THIRD_PARTY_NOTICES.txt`. رفع الملفات إلى مستودع عام يجعل كود الصفحة وملفاتها متاحة للعامة.
